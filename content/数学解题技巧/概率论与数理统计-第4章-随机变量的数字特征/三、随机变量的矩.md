# 三、随机变量的矩
## 矩的定义

设 (X,Y) 是二维随机变量。

如果

\[
E(X^kY^l)
\]

存在，则称

\[
E(X^k),\qquad k=1,2,\ldots
\]

为 X 的 k 阶原点矩；称

\[
E[(X-EX)^k],\qquad k=2,3,\ldots
\]

为 X 的 k 阶中心矩；称

\[
E(X^kY^l),\qquad k,l=1,2,\ldots
\]

为 X 与 Y 的 k+l 阶混合原点矩；称

\[
E[(X-EX)^k(Y-EY)^l],\qquad k,l=1,2,\ldots
\]

为 X 与 Y 的 k+l 阶混合中心矩。

由上述定义可知：

- 数学期望 EX 是 X 的一阶原点矩；
- 方差 D(X) 是 X 的二阶中心矩；
- 协方差 Cov(X,Y) 是 X 与 Y 的混合二阶中心矩。

## 例4.10

设随机变量 X 的概率密度为

\[
f(x)=\frac1{\sqrt\pi}\exp\left(-x^2+x-\frac14\right),
\qquad -\infty<x<+\infty.
\]

求随机变量 X 的二阶原点矩。

**分析：** 依题意，要求

\[
E(X^2).
\]

先对概率密度配方：

\[
-x^2+x-\frac14=-\left(x-\frac12\right)^2.
\]

于是

\[
f(x)=\frac1{\sqrt\pi}\exp\left[-\left(x-\frac12\right)^2\right]
=\frac1{\sqrt{2\pi}\sqrt{1/2}}
\exp\left[-\frac{(x-1/2)^2}{2\cdot(1/2)}\right].
\]

因此

\[
X\sim N\left(\frac12,\frac12\right).
\]

从而

\[
E(X)=\frac12,\qquad D(X)=\frac12.
\]

于是

\[
E(X^2)=D(X)+[E(X)]^2
=\frac12+\frac14
=\frac34.
\]

**评注：** 当遇到形如

\[
f(x)=A\exp[-(ax^2+bx+c)],
\qquad a>0,
\]

其中 b、c 为已知常数，A 为待定或已知常数，并把它作为随机变量 X 的密度函数时，一般称其为“正态密度方向法”。可先将指数部分配方为

\[
-\frac{1}{2\sigma^2}(x-\mu)^2+k,
\]

通过比较 x 的同次幂系数得到

\[
\sigma^2=\frac1{2a},
\qquad
\mu=-\frac{b}{2a},
\qquad
k=\frac{b^2}{4a}-c.
\]

通常只需简单识别即可得到参数。

# 一、随机变量的数学期望和方差
## （一）随机变量的数学期望的概念与性质

**1. 随机变量的数学期望的概念**

（1）离散型随机变量的数学期望

设离散型随机变量 X 的分布律为

\[
P\{X=x_i\}=p_i,\qquad i=1,2,\ldots
\]

若无穷级数

\[
\sum_{i=1}^{\infty}x_ip_i
\]

绝对收敛，则称该无穷级数的和为随机变量 X 的数学期望或均值，记作 EX 或 E(X)，即

\[
EX=\sum_{i=1}^{\infty}x_ip_i.\tag{4.1}
\]

（2）连续型随机变量的数学期望

设连续型随机变量 X 的概率密度为 f(x)，若反常积分

\[
\int_{-\infty}^{+\infty}xf(x)\,\mathrm{d}x
\]

绝对收敛，则称该反常积分的值为随机变量 X 的数学期望或均值，记为 EX 或 E(X)，即

\[
EX=\int_{-\infty}^{+\infty}xf(x)\,\mathrm{d}x.\tag{4.2}
\]

**注：**

1. 随机变量 X 的数学期望 E(X) 是一个实数。
2. 数学期望 E(X) 完全由随机变量 X 的概率分布所确定。若 X 服从某一分布，也称 E(X) 是这一分布的数学期望。
3. 若上述无穷级数或反常积分不绝对收敛，则称随机变量的数学期望不存在。

**2. 随机变量的数学期望的性质**

1. 设 C 是常数，则

\[
E(C)=C.
\]

2. 设 X 是随机变量，C 是常数，则

\[
E(CX)=CE(X).
\]

3. 设 X 和 Y 是任意两个随机变量，则

\[
E(X\pm Y)=E(X)\pm E(Y).
\]

4. 设随机变量 X 与 Y 相互独立，则

\[
E(XY)=E(X)E(Y).
\]

**注：** 性质4要求 X 与 Y 相互独立，该条件实际上可以减弱为 X 与 Y 不相关。事实上，等式

\[
E(XY)=E(X)E(Y)
\]

成立的充要条件是 X 与 Y 不相关。

## （二）随机变量函数的数学期望

**1. 一个随机变量 X 的函数 Y=g(X) 的数学期望**

（1）设 X 是离散型随机变量，其概率分布为

\[
P\{X=x_k\}=p_k,\qquad k=1,2,\ldots
\]

如果无穷级数

\[
\sum_{k=1}^{\infty}g(x_k)p_k
\]

绝对收敛，则随机变量

\[
Y=g(X)
\]

的数学期望为

\[
E(Y)=E[g(X)]=\sum_{k=1}^{\infty}g(x_k)p_k.\tag{4.3}
\]

（2）设连续型随机变量 X 的概率密度为 f(x)，如果反常积分

\[
\int_{-\infty}^{+\infty}g(x)f(x)\,\mathrm{d}x
\]

绝对收敛，则随机变量

\[
Y=g(X)
\]

的数学期望为

\[
E(Y)=E[g(X)]=\int_{-\infty}^{+\infty}g(x)f(x)\,\mathrm{d}x.\tag{4.4}
\]

**2. 二维随机变量 (X,Y) 的函数 Z=g(X,Y) 的数学期望**

（1）设二维离散型随机变量 (X,Y) 的概率分布为

\[
P\{X=x_i,Y=y_j\}=p_{ij},\qquad i,j=1,2,\ldots
\]

如果无穷级数

\[
\sum_{i=1}^{\infty}\sum_{j=1}^{\infty}g(x_i,y_j)p_{ij}
\]

绝对收敛，则随机变量

\[
Z=g(X,Y)
\]

的数学期望为

\[
E(Z)=E[g(X,Y)]=\sum_{i=1}^{\infty}\sum_{j=1}^{\infty}g(x_i,y_j)p_{ij}.\tag{4.5}
\]

（2）设二维连续型随机变量 (X,Y) 的概率密度为 f(x,y)，如果反常积分

\[
\int_{-\infty}^{+\infty}\int_{-\infty}^{+\infty}g(x,y)f(x,y)\,\mathrm{d}x\mathrm{d}y
\]

绝对收敛，则随机变量

\[
Z=g(X,Y)
\]

的数学期望为

\[
E(Z)=E[g(X,Y)]
=\int_{-\infty}^{+\infty}\int_{-\infty}^{+\infty}g(x,y)f(x,y)\,\mathrm{d}x\mathrm{d}y.\tag{4.6}
\]

## （三）随机变量的方差的概念及性质

**1. 方差及标准差的概念**

设 X 是一个随机变量，若

\[
E\left\{[X-E(X)]^2\right\}
\]

存在，则称其为 X 的方差，记为 D(X)，即

\[
D(X)=E\left\{[X-E(X)]^2\right\}.
\]

由定义可知

\[
D(X)\ge 0.
\]

方差的算术平方根称为 X 的均方差或标准差，记作

\[
\sigma(X)=\sqrt{D(X)}.
\]

称

\[
X^*=\frac{X-E(X)}{\sqrt{D(X)}}
\]

为 X 的标准化随机变量，此时

\[
E(X^*)=0,\qquad D(X^*)=1.
\]

**2. 方差的计算公式**

\[
D(X)=E(X^2)-[E(X)]^2.\tag{4.7}
\]

**3. 方差的重要性质**

1. 设 C 是常数，则

\[
D(C)=0.
\]

反之，由

\[
D(X)=0
\]

不能得出 X 为常数的结论。

2. 设 X 是随机变量，C 是常数，则

\[
D(X+C)=D(X).
\]

3. 设 X 是随机变量，C 是常数，则

\[
D(CX)=C^2D(X).
\]

4. 设随机变量 X 与 Y 相互独立，则

\[
D(X\pm Y)=D(X)+D(Y).
\]

5. 等式

\[
D(X)=0
\]

成立的充分必要条件是 X 以概率1取常数 C，即

\[
P\{X=C\}=1,
\]

其中

\[
C=E(X).
\]

## （四）常见随机变量的数学期望和方差

1. 若

\[
X\sim(0\text{-}1),\qquad P\{X=i\}=p^i(1-p)^{1-i},\quad i=0,1,
\]

则

\[
E(X)=p,\qquad D(X)=p(1-p).
\]

2. 若

\[
X\sim B(n,p),
\]

则

\[
E(X)=np,\qquad D(X)=np(1-p).
\]

3. 若

\[
X\sim P(\lambda),
\]

则

\[
E(X)=\lambda,\qquad D(X)=\lambda.
\]

4. 若 X 服从几何分布，即

\[
P\{X=k\}=p(1-p)^{k-1},\qquad k=1,2,\ldots,\quad 0<p<1,
\]

则

\[
E(X)=\frac{1}{p},\qquad D(X)=\frac{1-p}{p^2}.
\]

5. 若

\[
X\sim U(a,b),
\]

则

\[
E(X)=\frac{a+b}{2},\qquad D(X)=\frac{(b-a)^2}{12}.
\]

6. 若

\[
X\sim E(\lambda),
\]

则

\[
E(X)=\frac{1}{\lambda},\qquad D(X)=\frac{1}{\lambda^2}.
\]

7. 若

\[
X\sim N(\mu,\sigma^2),
\]

则

\[
E(X)=\mu,\qquad D(X)=\sigma^2.
\]

## 例4.1—例4.6

**例4.1**

假设有10只同种电子元件，其中有2只废品。装配仪器时，从这10只元件中任取一只，如果是废品，则扔掉后再重新任取一只；如果仍是废品，则扔掉后再任取一只。求在取到正品之前，已取出的废品只数的数学期望和方差。

**解：** 设 X 表示在取到正品之前已取出的废品只数，则 X 的可能取值为 0、1、2，其概率分布为

\[
P\{X=0\}=\frac{8}{10}=\frac45,
\]

\[
P\{X=1\}=\frac{2}{10}\cdot\frac89=\frac{8}{45},
\]

\[
P\{X=2\}=\frac{2}{10}\cdot\frac19\cdot1=\frac{1}{45}.
\]

于是

\[
E(X)=0\cdot\frac45+1\cdot\frac{8}{45}+2\cdot\frac{1}{45}=\frac29,
\]

\[
E(X^2)=0^2\cdot\frac45+1^2\cdot\frac{8}{45}+2^2\cdot\frac{1}{45}=\frac{4}{15}.
\]

所以

\[
D(X)=E(X^2)-[E(X)]^2
=\frac{4}{15}-\left(\frac29\right)^2
=\frac{88}{405}.
\]

**评注：** 求 E(X²) 时，也可以先求出 X² 的分布律，再求 E(X²) 的值。一般来说，先求出

\[
Y=g(X)
\]

的分布律，再求 E(Y)，要比直接利用随机变量函数的数学期望定义式更复杂。

**例4.2**

设随机变量

\[
X\sim E(1),\qquad Y=\max(X,1),
\]

则 E(Y) 等于多少？

（A）

\[
1
\]

（B）

\[
1+e^{-1}
\]

（C）

\[
1-e^{-1}
\]

（D）

\[
e^{-1}
\]

**分析：** 如果先求 Y 的密度，计算量很大。直接用随机变量函数的数学期望定义式，有

\[
E(Y)=E[\max(X,1)]
=\int_{-\infty}^{+\infty}\max(x,1)f(x)\,\mathrm{d}x,
\]

其中指数分布的密度函数为

\[
f(x)=
\begin{cases}
e^{-x},&x>0,\\
0,&x\le 0.
\end{cases}
\]

所以

\[
\begin{aligned}
E(Y)
&=\int_{-\infty}^{0}\max(x,1)\cdot0\,\mathrm{d}x
+\int_{0}^{+\infty}\max(x,1)e^{-x}\,\mathrm{d}x\\
&=\int_0^1e^{-x}\,\mathrm{d}x
+\int_1^{+\infty}xe^{-x}\,\mathrm{d}x\\
&=1-e^{-1}+2e^{-1}=1+e^{-1}.
\end{aligned}
\]

故选（B）。

**例4.3**

已知随机变量 X 与 Y 均服从 0-1 分布，且

\[
E(XY)=\frac58,
\]

求

\[
P\{|X+Y|\le1\}.
\]

（A）

\[
\frac18
\]

（B）

\[
\frac14
\]

（C）

\[
\frac38
\]

（D）

\[
\frac12
\]

**分析：** 由 X 与 Y 均服从 0-1 分布，可列出联合分布表：

联合分布中的四个概率记为

\[
P\{X=0,Y=0\}=p_{11},
\]

\[
P\{X=0,Y=1\}=p_{12},
\]

\[
P\{X=1,Y=0\}=p_{21},
\]

\[
P\{X=1,Y=1\}=p_{22}.
\]

由二维离散型随机变量函数的数学期望定义可知

\[
\begin{aligned}
E(XY)
&=0\cdot0\cdot P\{X=0,Y=0\}
+0\cdot1\cdot P\{X=0,Y=1\}\\
&\quad+1\cdot0\cdot P\{X=1,Y=0\}
+1\cdot1\cdot P\{X=1,Y=1\}\\
&=P\{X=1,Y=1\}=\frac58.
\end{aligned}
\]

因此

\[
p_{22}=\frac58.
\]

从而

\[
\begin{aligned}
P\{|X+Y|\le1\}
&=P\{X=0,Y=0\}+P\{X=0,Y=1\}+P\{X=1,Y=0\}\\
&=p_{11}+p_{12}+p_{21}=1-p_{22}=\frac38.
\end{aligned}
\]

故选（C）。

**例4.4**

已知随机变量 X 在区间 (1,2) 上服从均匀分布，在 X=x 条件下，Y 服从参数为 x 的指数分布，求 E(XY)。

**分析：** 由题设知条件密度为

\[
f_{Y\mid X}(y\mid x)=
\begin{cases}
xe^{-xy},&y>0,\\
0,&y\le0.
\end{cases}
\]

X 在 (1,2) 上服从均匀分布，故

\[
f_X(x)=
\begin{cases}
1,&1<x<2,\\
0,&\text{其他}.
\end{cases}
\]

所以联合密度函数为

\[
f(x,y)=f_X(x)f_{Y\mid X}(y\mid x)
=
\begin{cases}
xe^{-xy},&1<x<2,\ y>0,\\
0,&\text{其他}.
\end{cases}
\]

于是

\[
\begin{aligned}
E(XY)
&=\int_{-\infty}^{+\infty}\int_{-\infty}^{+\infty}xyf(x,y)\,\mathrm{d}x\mathrm{d}y\\
&=\int_1^2\mathrm{d}x\int_0^{+\infty}xy\cdot xe^{-xy}\,\mathrm{d}y\\
&=\int_1^2x\cdot\frac1x\,\mathrm{d}x=1.
\end{aligned}
\]

**注：**

\[
\int_0^{+\infty}yxe^{-xy}\,\mathrm{d}y=\frac1x,\qquad x>0,
\]

是参数为

\[
\lambda=x
\]

的指数分布的数学期望。

**例4.5**

已知某零件的横截面是一个圆，对横截面的直径进行测量，其值在区间 (1,2) 上服从均匀分布。求横截面面积的数学期望和方差。

**分析：** 设横截面的直径为 X，则 X 在区间 (1,2) 上服从均匀分布，概率密度为

\[
f_X(x)=
\begin{cases}
1,&1<x<2,\\
0,&\text{其他}.
\end{cases}
\]

且

\[
E(X)=\frac32,\qquad D(X)=\frac1{12}.
\]

设横截面的面积为 S，则

\[
S=\frac{\pi X^2}{4}.
\]

根据随机变量数学期望的性质与方差的计算公式，可得

\[
\begin{aligned}
E(S)
&=E\left(\frac{\pi X^2}{4}\right)
=\frac\pi4E(X^2)\\
&=\frac\pi4\left[D(X)+[E(X)]^2\right]\\
&=\frac\pi4\left[\frac1{12}+\left(\frac32\right)^2\right]
=\frac{7\pi}{12}.
\end{aligned}
\]

又

\[
D(S)=E(S^2)-[E(S)]^2,
\]

而

\[
E(S^2)=E\left(\frac{\pi^2X^4}{16}\right)
=\frac{\pi^2}{16}E(X^4).
\]

由随机变量函数的数学期望定义可知

\[
E(X^4)=\int_{-\infty}^{+\infty}x^4f_X(x)\,\mathrm{d}x
=\int_1^2x^4\,\mathrm{d}x
=\frac{31}{5}.
\]

于是

\[
E(S^2)=\frac{31\pi^2}{80},
\]

故

\[
D(S)=\frac{31\pi^2}{80}-\left(\frac{7\pi}{12}\right)^2
=\frac{17\pi^2}{360}.
\]

**例4.6**

设随机变量 X 和 Y 相互独立，且

\[
X\sim N(1,2),\qquad Y\sim N(-3,4),
\]

求随机变量

\[
Z=-2X+3Y+5
\]

的概率密度。

**分析：** 两个相互独立的正态随机变量的线性函数仍服从正态分布，因此 Z 服从正态分布。由数学期望与方差的性质及

\[
E(X)=1,\quad D(X)=2,\quad E(Y)=-3,\quad D(Y)=4,
\]

可得

\[
\begin{aligned}
E(Z)
&=E(-2X+3Y+5)\\
&=-2E(X)+3E(Y)+5\\
&=(-2)\cdot1+3\cdot(-3)+5=-6,
\end{aligned}
\]

\[
\begin{aligned}
D(Z)
&=D(-2X+3Y+5)\\
&=(-2)^2D(X)+3^2D(Y)\\
&=4\cdot2+9\cdot4=44.
\end{aligned}
\]

因此

\[
Z\sim N(-6,44),
\]

其概率密度为

\[
f(z)=\frac{1}{2\sqrt{22\pi}}
\exp\left[-\frac{(z+6)^2}{88}\right],
\qquad z\in\mathbb{R}.
\]

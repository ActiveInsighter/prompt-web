# 二、协方差与相关系数
对于二维随机变量 (X,Y)，其数字特征不仅包括 X 与 Y 的数学期望和方差，而且还包括描述 X 与 Y 之间相互关系的数字特征——协方差和相关系数。

## （一）协方差

**1. 协方差的概念**

设 (X,Y) 是二维随机变量，如果

\[
E[(X-EX)(Y-EY)]
\]

存在，则称其为随机变量 X 与 Y 的协方差，记作

\[
\operatorname{Cov}(X,Y),
\]

即

\[
\operatorname{Cov}(X,Y)=E[(X-EX)(Y-EY)].
\]

**2. 协方差的计算公式**

对任意两个随机变量 X 和 Y，有

\[
\operatorname{Cov}(X,Y)=E(XY)-E(X)E(Y).\tag{4.8}
\]

\[
D(X\pm Y)=D(X)+D(Y)\pm2\operatorname{Cov}(X,Y).\tag{4.9}
\]

**3. 协方差的性质**

1. 

\[
\operatorname{Cov}(X,Y)=\operatorname{Cov}(Y,X).
\]

2. 若 a、b 是常数，则

\[
\operatorname{Cov}(aX,bY)=ab\operatorname{Cov}(X,Y).
\]

3. 

\[
\operatorname{Cov}(X_1+X_2,Y)
=\operatorname{Cov}(X_1,Y)+\operatorname{Cov}(X_2,Y).
\]

## （二）相关系数

**1. 相关系数的概念**

如果 X、Y 的方差都存在且都不等于零，则称

\[
\frac{\operatorname{Cov}(X,Y)}{\sqrt{D(X)}\sqrt{D(Y)}}
\]

为随机变量 X 与 Y 的相关系数，记为

\[
\rho_{XY},
\]

即

\[
\rho_{XY}
=\frac{\operatorname{Cov}(X,Y)}{\sqrt{D(X)}\sqrt{D(Y)}}.
\]

**2. 相关系数的性质**

1. 

\[
|\rho_{XY}|\le1.
\]

2. 等式

\[
|\rho_{XY}|=1
\]

成立的充分必要条件是存在常数 a、b，使

\[
P\{Y=aX+b\}=1.
\]

**3. 随机变量 X 与 Y 不相关**

如果随机变量 X 与 Y 的相关系数为零，即

\[
\rho_{XY}=0,
\]

等价地

\[
\operatorname{Cov}(X,Y)=0,
\]

则称 X 与 Y 不相关。

关于随机变量 X 与 Y 的独立性与相关性，有如下结论：

1. 若 X 与 Y 独立，则 X 与 Y 一定不相关；但若 X 与 Y 不相关，则 X 与 Y 不一定独立。
2. 若 X 与 Y 的联合分布是二维正态分布，则 X 与 Y 独立的充要条件是 X 与 Y 不相关。
3. 若 X 与 Y 都服从 0-1 分布，则 X 与 Y 独立的充要条件是 X 与 Y 不相关。

**4. 对于随机变量 X 与 Y，下列四个结论等价**

\[
\operatorname{Cov}(X,Y)=0;
\]

\[
X\text{ 与 }Y\text{ 不相关};
\]

\[
E(XY)=E(X)E(Y);
\]

\[
D(X+Y)=D(X)+D(Y).
\]

## 例4.7—例4.9

**例4.7**

设随机变量 X 与 Y 独立同分布，记

\[
U=X-Y,\qquad V=X+Y,
\]

则随机变量 U 与 V 的关系为：

（A）不独立　（B）独立　（C）相关系数不为零　（D）相关系数为零

**分析：** 由于 X 与 Y 独立同分布，因此

\[
E(X)=E(Y),\qquad E(X^2)=E(Y^2).
\]

又

\[
E(U)=E(X-Y)=E(X)-E(Y)=0,
\]

\[
E(UV)=E[(X-Y)(X+Y)]=E(X^2-Y^2)=0.
\]

所以

\[
\operatorname{Cov}(U,V)=E(UV)-E(U)E(V)=0.
\]

从而 U 与 V 的相关系数为零，故选（D）。

由 X 与 Y 独立可以推出 U 与 V 不相关，但不能一般地推出 U 与 V 独立。若 X 与 Y 都服从正态分布，则 U 与 V 也都服从正态分布，从而 U 与 V 相互独立。

若 X 与 Y 服从同一 0-1 分布，则

\[
P\{X=0\}=P\{Y=0\}=\frac12,
\]

\[
P\{X=1\}=P\{Y=1\}=\frac12.
\]

于是

\[
P\{U=-1\}=P\{X=0,Y=1\}=\frac14,
\]

\[
P\{V=2\}=P\{X=1,Y=1\}=\frac14,
\]

但

\[
P\{U=-1,V=2\}=0.
\]

由于

\[
P\{U=-1,V=2\}\ne P\{U=-1\}P\{V=2\},
\]

故 U 与 V 不相互独立，选项（B）不正确。

**例4.8**

设随机变量

\[
X\sim N(0,1),\qquad Y\sim N(1,4),
\]

且相关系数

\[
\rho_{XY}=1,
\]

则下列哪一个等式以概率1成立？

（A）

\[
Y=-2X-1
\]

（B）

\[
Y=2X-1
\]

（C）

\[
Y=-2X+1
\]

（D）

\[
Y=2X+1
\]

**分析：** 因为

\[
\rho_{XY}=1>0,
\]

所以存在

\[
a>0
\]

使

\[
P\{Y=aX+b\}=1.
\]

由

\[
D(Y)=a^2D(X)
\]

得

\[
4=a^2,
\]

所以

\[
a=2.
\]

再由

\[
E(Y)=aE(X)+b
\]

得

\[
1=2\cdot0+b,
\]

所以

\[
b=1.
\]

故

\[
P\{Y=2X+1\}=1,
\]

选（D）。

**例4.9**

已知随机变量 X 与 Y 有相同的不为零的方差，则 X 与 Y 相关系数

\[
\rho=1
\]

的充要条件是：

（A）

\[
\operatorname{Cov}(X+Y,X)=0
\]

（B）

\[
\operatorname{Cov}(X+Y,Y)=0
\]

（C）

\[
\operatorname{Cov}(X+Y,X-Y)=0
\]

（D）

\[
\operatorname{Cov}(X-Y,X)=0
\]

**分析：** 设

\[
D(X)=D(Y)=\sigma^2>0.
\]

则

\[
\rho
=\frac{\operatorname{Cov}(X,Y)}{\sqrt{D(X)}\sqrt{D(Y)}}
=\frac{\operatorname{Cov}(X,Y)}{\operatorname{Cov}(X,X)}.
\]

因此

\[
\rho=1
\Longleftrightarrow
\operatorname{Cov}(X,Y)=\operatorname{Cov}(X,X)
\Longleftrightarrow
\operatorname{Cov}(X-Y,X)=0.
\]

故选（D）。

其余选项均不正确。因为当

\[
D(X)=D(Y)
\]

时，

\[
\operatorname{Cov}(X+Y,X)=0
\Longleftrightarrow
\rho=-1,
\]

\[
\operatorname{Cov}(X+Y,Y)=0
\Longleftrightarrow
\rho=-1,
\]

而

\[
\operatorname{Cov}(X+Y,X-Y)=0
\Longleftrightarrow
D(X)=D(Y).
\]

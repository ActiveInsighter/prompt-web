# 1.1 随机事件的关系与运算
## 1.1.1 随机事件与样本空间的概念

**1. 随机试验**

称一个试验为随机试验（简称试验），如果：

1. 试验可以在相同的条件下重复进行；
2. 每次试验的可能结果不止一个，并且能事先明确试验的所有可能结果；
3. 进行一次试验之前不能确定哪一个结果会出现。

随机试验用字母 \(E\) 或 \(E_1,E_2,\ldots\) 表示。

**2. 随机事件**

1. **基本事件与样本空间：** 随机试验最基本的结果称为基本事件或样本点，记作 \(\omega\)。每次试验必定出现且只能出现一个基本事件。一切基本事件的集合称为样本空间，记作 \(\Omega\)，即
   \[
   \Omega=\{\omega\}.
   \]
2. **随机事件：** 随机试验的一个结果称为随机事件，简称事件，用字母 \(A,B,C,\ldots\) 表示。事件可视为样本空间 \(\Omega\) 的子集。在每次试验中，当且仅当事件 \(A\) 所包含的某一基本事件出现时，称事件 \(A\) 发生。
3. 在每次试验中一定出现的结果称为必然事件，即样本空间 \(\Omega\)。在任何一次试验中都不会出现的结果称为不可能事件，即空集 \(\varnothing\)。

事件是集合，因此事件间的关系与事件的运算可按集合论中集合之间的关系和集合的运算处理。关于集合间的关系和集合的运算，应重点理解它们在概率中的含义。

## 1.1.2 事件间的关系与运算

| 事件间关系与运算的语言描述 | 集合论中的表示法 | 概率论中的含义 |
|---|---|---|
| 事件 \(A\) 包含事件 \(B\)（或事件 \(B\) 含于事件 \(A\)，或 \(B\) 发生导致 \(A\) 发生） | \(A\supset B\)（或 \(B\subset A\)） | 事件 \(B\) 发生，则事件 \(A\) 一定发生 |
| 事件 \(A\) 和 \(B\) 相等（或等价） | \(A=B\) | 事件 \(A\) 发生，则 \(B\) 一定发生，反之亦然 |
| 事件 \(A\) 与 \(B\) 之和（或并） | \(A\cup B\) 或 \(A+B\) | 事件 \(A,B\) 中至少有一个事件发生 |
| 有限个事件 \(A_1,A_2,\ldots,A_n\)（\(n\ge 2\)）的和（或并） | \(\displaystyle\bigcup_{i=1}^{n}A_i\) 或 \(\displaystyle\sum_{i=1}^{n}A_i\) | 事件 \(A_1,A_2,\ldots,A_n\) 中至少有一个事件发生 |
| 可列个事件 \(A_1,\ldots,A_n,\ldots\) 的和（或并） | \(\displaystyle\bigcup_{i=1}^{\infty}A_i\) 或 \(\displaystyle\sum_{i=1}^{\infty}A_i\) | 可列个事件 \(A_1,\ldots,A_n,\ldots\) 中至少有一个事件发生 |
| 事件 \(A\) 与 \(B\) 的积（或交） | \(A\cap B\)，简记为 \(AB\) | 事件 \(A\cap B\) 发生，当且仅当 \(A\) 与 \(B\) 同时发生 |
| 有限个事件 \(A_1,A_2,\ldots,A_n\)（\(n\ge 2\)）的积（或交） | \(A_1\cap A_2\cap\cdots\cap A_n\)，简记为 \(A_1A_2\cdots A_n\) | 事件 \(A_1,A_2,\ldots,A_n\) 同时发生 |
| 可列个事件 \(A_1,\ldots,A_n,\ldots\) 的积（或交） | \(\displaystyle\bigcap_{i=1}^{\infty}A_i\) | 可列个事件 \(A_1,\ldots,A_n,\ldots\) 同时发生 |
| 事件 \(A\) 与 \(B\) 的差 | \(A-B\) | 事件 \(A-B\) 发生，当且仅当事件 \(A\) 发生而 \(B\) 不发生 |
| 事件 \(A\) 的逆事件（或对立事件） | \(\overline A=\Omega-A\) | 事件 \(\overline A\) 发生，当且仅当事件 \(A\) 不发生 |
| 事件 \(A\) 和 \(B\) 互不相容（或 \(A\) 与 \(B\) 互斥） | \(A\cap B=\varnothing\) | 事件 \(A\) 与 \(B\) 不可能同时发生 |
| 事件 \(A_1,\ldots,A_n\) 是一个完备事件组 | \(\displaystyle\bigcup_{i=1}^{n}A_i=\Omega\)，且 \(A_iA_j=\varnothing\ (1\le i<j\le n)\) | \(n\) 个事件中仅发生且必发生其中之一 |
| 事件 \(A_1,A_2,\ldots\) 是一个完备事件组 | \(\displaystyle\bigcup_{i=1}^{\infty}A_i=\Omega\)，且 \(A_iA_j=\varnothing\ (1\le i<j<\infty)\) | 可列个事件中仅发生且必发生其中之一 |

## 1.1.4 事件的运算性质

设 \(A,B,C,A_i\ (i=1,2,\ldots)\) 为事件，则有：

1. **吸收律：** 若 \(A\subset B\)，则
   \[
   A\cup B=B,\qquad AB=A.
   \]
2. **交换律：**
   \[
   A\cup B=B\cup A,\qquad AB=BA.
   \]
3. **结合律：**
   \[
   A\cup B\cup C=(A\cup B)\cup C=A\cup(B\cup C),
   \]
   \[
   ABC=(AB)C=A(BC).
   \]
4. **分配律：**
   \[
   A(B\cup C)=AB\cup AC,
   \]
   \[
   A\cup(BC)=(A\cup B)(A\cup C),
   \]
   \[
   (A\cup C)(B\cup C)=AB\cup C,
   \]
   \[
   A\cap\left(\bigcup_{i=1}^{\infty}A_i\right)
   =\bigcup_{i=1}^{\infty}(A\cap A_i).
   \]
5. **对偶律：**
   \[
   \overline{A\cup B}=\overline A\,\overline B,
   \qquad
   \overline{A\cap B}=\overline A\cup\overline B,
   \]
   \[
   \overline{\bigcup_{i=1}^{n}A_i}=\bigcap_{i=1}^{n}\overline{A_i},
   \qquad
   \overline{\bigcap_{i=1}^{n}A_i}=\bigcup_{i=1}^{n}\overline{A_i}.
   \]

**【例 1.1】** 设 \(A,B,C\) 为随机事件，\(A\) 发生必导致 \(B\) 与 \(C\) 最多一个发生，则有：

- （A）\(A\subset BC\)
- （B）\(A\supset BC\)
- （C）\(A\subset\overline{BC}\)
- （D）\(A\supset\overline{BC}\)

**分析：** \(B\) 与 \(C\) 最多有一个发生，就是 \(B\) 与 \(C\) 不可能同时发生，即
\[
BC=\varnothing.
\]
从而
\[
\overline{BC}=\Omega,
\]
故
\[
A\subset\overline{BC}=\Omega.
\]
选（C）。

**【例 1.2】** 已知
\[
(A\cup\overline X)(\overline A\cup\overline X)
\cup\overline{A\cup X}
\cup\overline{\overline A\cup X}=B,
\]
则 \(X=\underline{\qquad}\)。

**分析：** 由事件的运算性质，
\[
(A\cup\overline X)(\overline A\cup\overline X)
=A\overline A\cup\overline X
=\varnothing\cup\overline X
=\overline X,
\]
\[
\overline{A\cup X}\cup\overline{\overline A\cup X}
=\overline A\,\overline X\cup A\overline X
=(A\cup\overline A)\overline X
=\overline X.
\]
于是原式左端为 \(\overline X=B\)，从而
\[
X=\overline B.
\]

> **评注：** 事件运算的一般顺序为：“括号”\(\rightarrow\)“逆”\(\rightarrow\)“积”\(\rightarrow\)“和”或“差”。

**【例 1.3】** 设随机事件 \(A,B\) 满足条件
\[
A\cup C=B\cup C,
\qquad
C-A=C-B,
\]
则
\[
A\overline B\cup\overline A B=\underline{\qquad}.
\]

**分析一：** 由
\[
C-A=C-B
\]
得
\[
C\overline A=C\overline B. \tag{1}
\]
又由
\[
A\cup C=B\cup C
\]
得
\[
\overline A\,\overline C=\overline B\,\overline C. \tag{2}
\]
由（1）与（2）可得
\[
C\overline A+\overline C\,\overline A
=C\overline B+\overline C\,\overline B,
\]
即 \(\overline A=\overline B\)，亦即 \(A=B\)。因此
\[
A\overline B\cup\overline A B
=B\overline B\cup\overline B B
=\varnothing.
\]

**分析二：**
\[
A=(A\cup C)-(C-A)=(B\cup C)-(C-B)=B,
\]
所以
\[
A\overline B\cup\overline A B=\varnothing.
\]

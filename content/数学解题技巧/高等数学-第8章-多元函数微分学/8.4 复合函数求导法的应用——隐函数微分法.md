# 8.4 复合函数求导法的应用——隐函数微分法
## 8.4.1 由方程式确定的隐函数求导法

**▶ 1. 由一个方程式确定的一元隐函数求导法**
**【定理8.9】** (隐函数存在定理) 如果二元方程 \(F(x,y) = 0\) 满足如下三个条件: ① 函数 \(F(x,y)\) 在点 \((x_0,y_0)\) 某邻域有连续的偏导数, ② \(F(x_0,y_0) = 0\) , ③ \(F_{y}^{\prime}(x_0,y_0) \neq 0\) , 则方程 \(F(x,y) = 0\) 在点 \((x_0,y_0)\) 某邻域恒能唯一确定一个连续函数 \(y = y(x)\) , 它满足 \(y_0 = y(x_0)\) , 并有连续的导数, 且
\[y^{\prime} = \frac{\mathrm{d}y}{\mathrm{d}x} = - \frac{F_{x}^{\prime}}{F_{y}^{\prime}}. \quad (8.5)\]

**【注】** 该定理的三个条件中关键是 \(F_{y}^{\prime}(x_0,y_0) \neq 0\) , 就可确定隐函数 \(y = y(x)\) , 而且 \(y_0 = y(x_0)\) . 如果也有 \(F_{x}^{\prime}(x_0,y_0) \neq 0\) , 当然该方程也能在 \(y_0\) 的某邻域确定隐函数 \(x = x(y)\) , 而且 \(x_0 = x(y_0)\) .
求此时隐函数的导数的方法是: 在 \((x_0,y_0)\) 邻域将恒等式 \(F(x,y(x)) = 0\) 两边对 \(x\) 求导, 应用复合函数求导法可得 \(F_{x}^{\prime} + F_{y}^{\prime}y^{\prime} = 0\) , 解出 \(y^{\prime}\) 就得 (8.5) .

**2. 由一个方程式确定的二元隐函数求导法**
**【定理8.10】** (隐函数存在定理)如果三元方程 \(F(x,y,z) = 0\) 满足如下三个条件: ① 函数 \(F(x,y,z)\) 在点 \((x_{0},y_{0},z_{0})\) 某邻域有连续偏导数, ② \(F(x_{0},y_{0},z_{0}) = 0\) , ③ \(F_{z}^{\prime}(x_{0},y_{0},z_{0})\neq 0\) ,则此方程在点 \((x_{0},y_{0},z_{0})\) 某邻域恒能唯一确定一个连续函数 \(z = z(x,y)\) ,它满足 \(z_{0} = z(x_{0},y_{0})\) ,并有连续的偏导数,且
\[\frac{\partial z}{\partial x} = - \frac{F_{x}^{\prime}}{F_{z}^{\prime}},\quad \frac{\partial z}{\partial y} = - \frac{F_{y}^{\prime}}{F_{z}^{\prime}}. \quad (8.6)\]

(1)求由方程 \(F(x,y,z) = 0\) 确定的隐函数 \(z = z(x,y)\) 的一阶偏导数的方法.
**方法 \(1^{\circ}\)** 由 \(F(x,y,z(x,y)) = 0\) 分别对自变量 \(x,y\) 求偏导数,应用复合函数求导法得
\[F_{x}^{\prime} + F_{z}^{\prime}\frac{\partial z}{\partial x} = 0,\qquad F_{y}^{\prime} + F_{z}^{\prime}\frac{\partial z}{\partial y} = 0,\]
分别解出 \(\frac{\partial z}{\partial x},\frac{\partial z}{\partial y}\) 就得(8.6).

**方法 \(2^{\circ}\)** 利用一阶全微分形式不变性.对方程 \(F(x,y,z) = 0\) 两边求全微分得
\[\mathrm{d}F(x,y,z) = 0,\mathrm{~}\mathrm{d}F_{x}^{\prime}\mathrm{d}x + F_{y}^{\prime}\mathrm{d}y + F_{z}^{\prime}\mathrm{d}z = 0,\]
从而当 \(F_{z}^{\prime}\neq 0\) 时 \(\mathrm{d}z = -\left(\frac{F_{x}^{\prime}}{F_{z}^{\prime}}\mathrm{d}x + \frac{F_{y}^{\prime}}{F_{z}^{\prime}}\mathrm{d}y\right)\) ;于是有 \(\frac{\partial z}{\partial x} = - \frac{F_{x}^{\prime}}{F_{z}^{\prime}},\quad \frac{\partial z}{\partial y} = - \frac{F_{y}^{\prime}}{F_{z}^{\prime}}.\)

**方法 \(3^{\circ}\)** 直接代公式(8.6)求出 \(\frac{\partial z}{\partial x}\) 与 \(\frac{\partial z}{\partial y}\).

(2)求由方程 \(F(x,y,z) = 0\) 确定的隐函数 \(z = z(x,y)\) 的二阶偏导数的方法.
若函数 \(F(x,y,z)\) 具有二阶连续偏导数,则隐函数 \(z = z(x,y)\) 也具有二阶连续偏导数,此时还可求 \(z = z(x,y)\) 的二阶偏导数.必须注意:上面的 \(F_{x}^{\prime},F_{y}^{\prime},F_{z}^{\prime}\) 仍然是 \(x,y,z\) 的函数,而 \(z\) 又是 \(x,y\) 的函数.下面求 \(\frac{\partial^{2}z}{\partial x^{2}}\) .

**方法 \(1^{\circ}\)** 将 \(F_{x}^{\prime} + F_{z}^{\prime}\frac{\partial z}{\partial x} = 0\) 两边对 \(x\) 求偏导数.先改写成 \(F_{1}^{\prime} + F_{3}^{\prime}\frac{\partial z}{\partial x} = 0\) ,两边对 \(x\) 求偏导数得
\[\frac{\partial}{\partial x} (F_{1}^{\prime}) + \frac{\partial}{\partial x} (F_{3}^{\prime})\frac{\partial z}{\partial x} +F_{3}^{\prime}\frac{\partial^{2}z}{\partial x^{2}} = 0,\]
即 \(F_{11}^{\prime \prime} + F_{13}^{\prime \prime}\frac{\partial z}{\partial x} +\left(F_{31}^{\prime \prime} + F_{33}^{\prime \prime}\frac{\partial z}{\partial x}\right)\frac{\partial z}{\partial x} +F_{3}^{\prime}\frac{\partial^{2}z}{\partial x^{2}} = 0,\)
移项,得 \(\frac{\partial^{2}z}{\partial x^{2}} = -\left[F_{11}^{\prime \prime} + 2F_{13}^{\prime \prime}\frac{\partial z}{\partial x} +F_{33}^{\prime \prime}\left(\frac{\partial z}{\partial x}\right)^{2}\right] / F_{3}^{\prime}.\)
将 \(\frac{\partial z}{\partial x}\) 的表达式代入得 \(\frac{\partial^{2}z}{\partial x^{2}} = \left[2F_{13}^{\prime \prime}F_{1}^{\prime}F_{3}^{\prime} - F_{11}^{\prime \prime}(F_{3}^{\prime})^{2} - F_{33}^{\prime \prime}(F_{1}^{\prime})^{2}\right] / (F_{3}^{\prime})^{3},\) (8.7)

或 \(\frac{\partial^{2}z}{\partial x^{2}} = \left[2\frac{\partial^{2}F}{\partial x\partial z}\frac{\partial F}{\partial x}\frac{\partial F}{\partial z} -\frac{\partial^{2}F}{\partial x^{2}}\left(\frac{\partial F}{\partial z}\right)^{2} - \frac{\partial^{2}F}{\partial z^{2}}\left(\frac{\partial F}{\partial x}\right)^{2}\right] / \left(\frac{\partial F}{\partial z}\right)^{3}.\) (8.8)

**方法 \(2^{\circ}\)** 将 \(\frac{\partial z}{\partial x}\) 的表达式(8.6)再对 \(x\) 求偏导数:
\[\frac{\partial^{2}z}{\partial x^{2}} = \frac{\partial}{\partial x}\left(-\frac{F_{1}^{\prime}}{F_{3}^{\prime}}\right) = -\frac{\frac{\partial}{\partial x}\left(F_{1}^{\prime}\right)F_{3}^{\prime} - F_{1}^{\prime}\frac{\partial}{\partial x}\left(F_{3}^{\prime}\right)}{\left(F_{3}^{\prime}\right)^{2}}\]
\[= -\left[\left(F_{11}^{\prime \prime} + F_{13}^{\prime \prime}\frac{\partial z}{\partial x}\right)F_{3}^{\prime} - F_{1}^{\prime}\left(F_{31}^{\prime \prime} + F_{33}^{\prime \prime}\frac{\partial z}{\partial x}\right)\right] / (F_{3}^{\prime})^{2},\]
将 \(\frac{\partial z}{\partial x} = - F_{1}^{\prime} / F_{3}^{\prime}\) 代入,同样可得(8.7)或(8.8).

## 8.4.2 由方程组确定的隐函数求导法

**1. 由方程组确定的一元隐函数求导法**
设有3个变量2个方程构成的方程组 \(\left\{ \begin{array}{l}F(x,u,v) = 0,\\ G(x,u,v) = 0, \end{array} \right.\) 其中 \(F,G\) 有连续偏导数.若在区间 \(I\) 上存在函数组 \(u = u(x),v = v(x)\) 满足该方程组,则说此方程组确定了隐函数 \(u = u(x),v = v(x)\) .若它们可导并求 \(\frac{\mathrm{d}u}{\mathrm{d}x}\) 与 \(\frac{\mathrm{d}v}{\mathrm{d}x}\) 则由 \(F(x,u(x),v(x)) = 0,G(x,u(x),v(x)) = 0\) 两边分别对 \(x\) 求导,应用复合函数求导法则可得
\[\left\{ \begin{array}{l} F_{x} + F_{u}u^{\prime} + F_{v}v^{\prime} = 0, \\ G_{x} + G_{u}u^{\prime} + G_{v}v^{\prime} = 0. \end{array} \right.\]
这可看成是以 \(\frac{\mathrm{d}u}{\mathrm{d}x},\frac{\mathrm{d}v}{\mathrm{d}x}\) 为未知量的二元一次方程组,可利用克莱姆法则求出 \(\frac{\mathrm{d}u}{\mathrm{d}x}\) 与 \(\frac{\mathrm{d}v}{\mathrm{d}x}\) .

**2. 由方程组确定的二元隐函数求导法**
设有4个变量2个方程构成的方程组 \(\left\{ \begin{array}{l}F(x,y,u,v) = 0,\\ G(x,y,u,v) = 0 \end{array} \right.\) 确定隐函数 \(u = u(x,y),v = v(x,y)\) ,其中 \(F,G\) 有连续的偏导数.若 \(u(x,y),v(x,y)\) 可偏导并求 \(\frac{\partial u}{\partial x}\) 与 \(\frac{\partial v}{\partial x}\left(\frac{\partial u}{\partial y} +\frac{\partial u}{\partial y}\right)\) 则由 \(F(x,y,u(x,y),v(x,y)) = 0,G(x,y,u(x,y),v(x,y)) = 0\) 两边分别对 \(x,y\) 求偏导数,应用复合函数求导法则即得
\[\left\{ \begin{array}{l} F_{x} + F_{u}u_{x} + F_{v}v_{x} = 0, \\ G_{x} + G_{u}u_{x} + G_{v}v_{x} = 0. \end{array} \right. \quad \left\{ \begin{array}{l} F_{y} + F_{u}u_{y} + F_{v}v_{y} = 0, \\ G_{y} + G_{u}u_{y} + G_{v}v_{y} = 0. \end{array} \right.\]
这分别可看成是以 \(\frac{\partial u}{\partial x}\) 与 \(\frac{\partial v}{\partial x}\left(\frac{\partial u}{\partial y} +\frac{\partial v}{\partial y}\right)\) 的二元一次方程组,可利用克莱姆法则求出 \(\frac{\partial u}{\partial x}\) 与 \(\frac{\partial v}{\partial x}\left(\frac{\partial u}{\partial y} +\frac{\partial v}{\partial y}\right)\) .

**【例8.8】** 设 \(u = f(x,y,z,t)\) 关于各变量均有连续偏导数,而其中由方程组
\[\left\{ \begin{array}{l} z = ye^{x} + t^{2}, \\ y^{2}e^{z} + t^{2}e^{y} = 0 \end{array} \right. \quad (1)\]
确定 \(z,t\) 为 \(y\) 的函数,求 \(\frac{\partial u}{\partial x}\) 与 \(\frac{\partial u}{\partial y}\) .
**【解】** 注意 \(z = z(y),t = t(y)\) ,于是
\[\frac{\partial u}{\partial x} = f_{x}^{\prime} + f_{z}^{\prime}\frac{\partial z}{\partial x} + f_{t}^{\prime}\frac{\partial t}{\partial x} \xlongequal{\frac{\partial z}{\partial x}=\frac{\partial t}{\partial x}=0} f_{x}^{\prime},\]
\[\frac{\partial u}{\partial y} = f_{y}^{\prime} + f_{z}^{\prime}\frac{\mathrm{d}z}{\mathrm{d}y} + f_{t}^{\prime}\frac{\mathrm{d}t}{\mathrm{d}y}. \quad (2)\]
因此,我们还要求 \(\frac{\mathrm{d}z}{\mathrm{d}y}\) 与 \(\frac{\mathrm{d}t}{\mathrm{d}y}\) ,将方程组 \(①\) 两边对 \(y\) 求导得
\[\begin{aligned} \frac{\mathrm{d}z}{\mathrm{d}y} &= e^{x} + 2t\frac{\mathrm{d}t}{\mathrm{d}y}, \\ 2ye^{z} + y^{2}e^{z}\frac{\mathrm{d}z}{\mathrm{d}y} + 2t e^{y}\frac{\mathrm{d}t}{\mathrm{d}y} + t^{2}e^{y} &= 0 \end{aligned} \quad \Rightarrow \quad \left\{ \begin{array}{l} -2t \frac{\mathrm{d}t}{\mathrm{d}y} + \frac{\mathrm{d}z}{\mathrm{d}y} = e^{x} \\ y^{2}e^{z}\frac{\mathrm{d}z}{\mathrm{d}y} + 2te^{y}\frac{\mathrm{d}t}{\mathrm{d}y} = -(2ye^{z}+t^{2}e^{y}) \end{array} \right.\]

\[\Rightarrow \quad \left\{ \begin{array}{l} (y^{2}e^{z} + 2t^{2}e^{y})\frac{\mathrm{d}z}{\mathrm{d}y} = (2y + t^{2})e^{y} - 2t e^{x+y} \\ (y^{2}e^{z} + 2t^{2}e^{y})\frac{\mathrm{d}t}{\mathrm{d}y} = - \frac{2y e^{z} + t^{2}e^{y}}{2t} - \frac{y^{2}e^{z+x}}{2t} \end{array} \right.\]
记系数行列式为 \(W = (y^{2}e^{z} + 2t^{2}e^{y})\) ,则
\[\frac{\mathrm{d}z}{\mathrm{d}y} = \frac{(2y + t^{2})e^{y} - 2t e^{x+y}}{W}, \quad \frac{\mathrm{d}t}{\mathrm{d}y} = -\frac{2y e^{z} + t^{2}e^{y} + y^{2}e^{z+x}}{2t W}.\]
代入 \(②\) 得 \(\frac{\partial u}{\partial y} = f_{y}^{\prime} + \frac{e^{y}(2y + t^{2}) - 2t e^{x+y}}{W} f_{z}^{\prime} - \frac{2y e^{z} + t^{2}e^{y} + y^{2}e^{z+x}}{2t W} f_{t}^{\prime}.\)
